## About

**Architecture first, features follow.**

Most of what I ship runs quietly in production.

### What I optimize for

| Area | Focus |
| --- | --- |
| **System design** | Enterprise shapes scoped before the first sprint. Trade-offs written plain. |
| **Infrastructure** | Fault-tolerant backends, deploy paths, and data layers that hold under load. |
| **Microservices** | Distributed systems with tenancy, APIs, and boundaries a team can extend. |
| **Technical planning** | Roadmaps and foundations you can brief against, not slide decks that age out. |
| **AI integration** | LLMs, automation, and local inference wired into products where they cut real work. |

### How I work

- I own the slice I promise: schema, APIs, deploy, and the awkward edge cases in between.
- Security by design: OAuth, Keycloak, JWT, and tenancy isolation when the product needs it.
- AI lands in the product when it removes real work. Privacy and API cost belong in the first release, not a late rework before launch.
- Documentation and handoff for the next engineer. No tribal knowledge traps.
- CI/CD and deploy paths that stay boring on purpose.
- I write and ship so the next engineer on the team is not guessing my intent.
