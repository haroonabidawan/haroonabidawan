## About

**Architecture first, features follow.**

Most of what I ship runs quietly in production. Five-plus years of enterprise backends, SaaS, and automation at Bespoke Marketing and earlier roles across the GCC.

### What I optimize for

| Area | Focus |
| --- | --- |
| **System design** | Enterprise shapes scoped before the first sprint. Trade-offs written plain. |
| **Infrastructure** | Fault-tolerant backends, deploy paths, and data layers that hold under load. |
| **Microservices** | Distributed systems with tenancy, APIs, and boundaries a team can extend. |
| **Technical planning** | Roadmaps and foundations you can brief against, not slide decks that age out. |
| **AI integration** | LLMs, automation, and local inference wired into products where they cut real work. |

### How I work

- I own the slice I promise: schema, APIs, deploy, and the awkward edge cases in between.
- Security by design: OAuth, Keycloak, JWT, and tenancy isolation when the product needs it.
- AI lands when it removes real work. Privacy and API cost belong in the first release.
- Documentation and handoff for the next engineer. No tribal knowledge traps.
- CI/CD and deploy paths that stay boring on purpose.

## This repository

Personal portfolio site for [haroonabidawan.com](https://haroonabidawan.com). **Carbon Trail** brand: dark surface, sage accent, Space Grotesk + JetBrains Mono, mobile-first navigation.

### Tech

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Motion

### Branches

Public repo. Three deploy lanes only.

| Branch | Use | Vercel |
| --- | --- | --- |
| **`production`** | Live site at [haroonabidawan.com](https://haroonabidawan.com). Default branch. | Production deploy |
| **`stage`** | Pre-production QA and client review. | Preview deploy only |
| **`dev`** | Active development and experiments. | Not deployed |

Vercel branch rules live in `vercel.json`. In the Vercel dashboard: **Settings → Git → Production Branch** → set to **`production`**.

```bash
git checkout dev        # daily work
git checkout stage      # merge dev when ready to preview
git checkout production # merge stage when ready to ship
```

### Local development

Requires [pnpm](https://pnpm.io/).

```bash
pnpm install
cp .env.example .env.local   # add NEXT_PUBLIC_GA_MEASUREMENT_ID
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
pnpm build    # production build
pnpm start    # run production server locally
pnpm lint     # ESLint
```
